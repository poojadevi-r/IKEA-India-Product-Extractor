\# IKEA India Full Catalog Product Extractor



\## Project Overview

A Python-based data extraction project that collects IKEA India product information from its product listing API and organizes the results into structured CSV and JSON files.



\## Technologies

\- Python

\- Requests

\- BeautifulSoup

\- CSV and JSON

\- Regular expressions

\- Concurrent processing with ThreadPoolExecutor



\## Key Features

\- Discovers product category IDs from the IKEA India products page.

\- Retrieves product listing data through HTTP requests with retry handling.

\- Extracts product and nested variant article records.

\- Captures product IDs, names, prices, offer prices, discounts, ratings, URLs, images, colors, sizes, badges, and product types where available.

\- Builds a complete category breadcrumb.

\- Normalizes product records into defined CSV columns.

\- Saves raw product data, category metadata, and progress information.

\- Uses concurrent category processing to speed up extraction.

\## How to Run

1\. Install Python 3.

2\. Install the required libraries:



```bash

pip install requests beautifulsoup4

```



3\. Run the script from the project directory:



```bash

python ikea\_product\_extractor.py

```



4\. Review the generated files in `ikea\_output/`.



\## Data Fields

The CSV output includes category hierarchy, product and variant IDs, product name, price, offer price, discount, rating, rating count, product URL, image URLs, badges, colors, size, pack size, product type, and description.



Some fields may be blank when the source does not provide them.
